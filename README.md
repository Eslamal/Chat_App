# 💬 Simple Chat App (Java + Firebase)

## 📱 Overview

This is a simple real-time chat application built using **Java**, **XML layouts**, and **Firebase**. 
It enables users to register/login, send and receive messages instantly using **Cloud Firestore**, and manage user authentication via **Firebase Authentication**.


## 🚀 Features

- 🔐 **User Authentication** (Email & Password using Firebase Auth)
- 💬 **Real-time Messaging** using Firebase Cloud Firestore
- 👥 **User List** with live status (optional)
- 📩 **RecyclerView-based Chat Interface**
- ⏰ **Message Timestamps**
